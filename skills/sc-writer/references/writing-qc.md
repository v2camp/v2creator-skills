# Writing QC: 四层写作质检

草稿写完后的**写作内闭环**检查。只判断「写得好不好、像不像作者」，不判断「能不能发」。

| | 本文件（写作质检） | `sc-content-review`（发布前审计） |
|--|-------------------|----------------------------------|
| 管什么 | 主张、结构、口吻、节奏、可读性 | 平台红线、事实核查、链接健康 |
| 何时跑 | Draft 完成时 | 发布前 |
| 产出 | 质检报告 + 返工优先级 | 合规/事实/链接报告 |
| 是否改稿 | 指出问题，可给改法 | 不改稿 |

两份报告**不互相替代**，不要把禁用词表双份维护：平台极限词归 `sc-content-review`，AI 味/口吻禁区归 `voice.md` + 本文件 L1。

## L1 硬性规则（机扫层）

任一命中必须修，无例外。

1. **AI 味词**：对照 `voice.md` 通用禁区表（说白了 / 这意味着 / 本质上 / 综上所述 / 值得注意的是 / 在当今…时代 等）。
2. **口吻禁区**：作者档案「绝对禁区」中的词与句式。
3. **虚构经历**：出现第一人称经历却无素材支撑的，标注删除或改为「尚未亲测」。
4. **无源事实**：数字、引语、研究成果无出处；有 Source map 的以 map 为准。
5. **空泛专名**：「某工具 / 某模型 / 相关技术」未落到具体名称。

**通过**：零命中。

## L2 风格一致性（对照 Voice Profile）

| 检查项 | 要点 |
|--------|------|
| 开头 | 是否具体场景/事件切入？是否踩中「开头签名」？ |
| 节奏 | 长短句是否交替？过长段是否按平台 style 切开？ |
| 转场 | 板块衔接是否口语，而非「接下来我们看」？ |
| 判断句型 | 下结论是否像作者，而非教科书？ |
| 情绪外化 | 是否有作者允许的自嘲/短句/语气？（按档案，不强求） |

**通过**：开头与判断句型全过；其余允许 1 项弱（须写明）。

## L3 内容质量（深度层）

| 检查项 | 要点 |
|--------|------|
| 主张支撑 | Core claim 有具体人/事/数据/步骤，不是空论断 |
| 反方回应 | Counter-view 在正文中被认真对待一段 |
| 知识输出 | 原理是否「聊到才掏出来」，而非「下面我来科普」 |
| 具体 > 抽象 | 每节至少一处可指认细节（步骤、数字、原话） |
| 类型专项 | 方法论：每节有可执行动作并坦诚成本；故事：有过程与发现；测评：有真实场景对比 |

**通过**：前四项必过；类型专项按文类计。

## L4 可读性终审（读者层）

不做逐项扫描，以目标读者身份通读全文，回答：

> **「这像一个懂行的人在认真跟我讲一件事，还是像系统在输出信息？」**

- **温度**：情绪是体感（「我当时就愣住了」）还是知识性描述（「令人震撼」）？
- **独特**：换一个作者是否也能原样写出？若有作者独家细节/角度，是否保留？
- **姿态**：有没有滑入「导师训话」或「品牌软文」？
- **心流**：何处需要回头补逻辑？标记段落位置。

**通过**：无明显「这段 AI 味重」。有则返工改写该段，不整篇推翻。

```markdown
## 写作质检报告

**L1 硬性规则** ✅/❌
- AI 味词：X 处（已修/待修）
- 口吻禁区：X 处
- 虚构经历：X 处
- 无源事实：X 处
- 空泛专名：X 处

**L2 风格** ✅/❌
- 开头：✅/❌
- 节奏：✅/❌（问题：…）
- 转场：✅/❌
- 判断句型：✅/❌
- 情绪外化：✅/❌/不适用

**L3 内容** ✅/❌
- 主张支撑 / 反方回应 / 知识输出 / 具体度 / 类型专项：✅/❌

**L4 可读性** ✅/❌
- 温度 / 独特 / 姿态 / 心流：✅/❌（断点或 AI 味段落：…）

**总评**：四层全过 / 第 N 层待返工
**修复优先级**：1. … 2. … 3. …
```

## 阈值说明

报告中如出现「口语转场 ≥N 次」「短段占比 ≥P%」等数字，均为**建议值 + 本地标定**，不作为发布门禁。
