# Voice: 口吻规格

结构对了只能算「合格稿」；口吻决定「像谁写的、读不读得下去」。本文件定义**如何给作者立口吻规格**，并在写作全程生效。

与平台 style 的分工：`wechat-style` / `xhs-style` 管排版与平台合规；本文件管**句子怎么说、判断怎么下、哪里像活人**。

## 口吻档案（Voice Profile）七维

给任何作者/账号写口吻规格时，固定填这七维。缺一维就不完整：

| 维 | 问什么 | 落到文中的形态 |
|----|--------|----------------|
| **1. 价值观底色** | 这个人相信什么、不追什么 | 选题取舍、判断姿态 |
| **2. 读者关系** | 对读者是老师/同伴/先行者？ | 称谓、语气、是否下场示范 |
| **3. 判断句型** | 下结论时习惯怎么说 | 「我觉得」「说句实话」「数据上看」 |
| **4. 转场与口癖** | 板块之间怎么衔接 | 口语转场句、高频短语 |
| **5. 情绪与标点** | 兴奋/无语/自嘲如何外化 | 感叹、省略、语气词、括号补刀 |
| **6. 绝对禁区** | 一出现就穿帮的词与写法 | 禁用词表、禁用句式 |
| **7. 开头/收尾签名** | 习惯怎么起、怎么收 | 开头类型偏好、收尾类型偏好 |

## 写作中如何生效

1. **Outline**：在 `Voice notes` 写 1–3 条本文口吻要点（例如「偏同伴口吻，多下场例子」「方法论节要先自谦」）。
2. **Draft**：每段写完自查第 3–5 维——判断句型是否像作者、转场是否口语、情绪是否外化。
3. **QC**：`writing-qc.md` 的 L2/L4 直接对照本档案打分。

## AI 味通用禁区（与作者无关）

下列模式几乎必穿帮，**默认全文禁用**，除非某作者档案显式保留：

| 类型 | 示例 | 替换方向 |
|------|------|----------|
| 套话起承 | 首先…其次…最后；综上所述；值得注意的是 | 口语转场或直接删 |
| 空转判断 | 说白了；这意味着；本质上；换句话说 | 具体判断或口语表达 |
| 教科书开头 | 在当今…的时代；随着…的发展 | 一个具体场景/事件 |
| 假设性经历 | 「比如有一次我…」（并无此事） | 真实细节，或改为「我还没试过，但…」 |
| 空泛专名 | 某 AI 工具；某个模型；相关技术 | 具体产品/模型名 |
| 过度结构化 | 连续 bullet 堆观点、满屏加粗 | 散文叙述 + 有限列表 |
| 通用比喻 | 「就像…一样」随手贴 | 有体感的细节比喻，或删 |

## 推荐口语转场（通用池，按作者档案取舍）

- 顺着上面的，再聊一块。
- 说到这个，我想起一件事。
- 回到最开始那个问题。
- 这块要注意一下，不是说 X 不好，而是…
- 说实话，我自己也踩过这个坑。
- 你也可以回想一下。

## 口吻档案示例（few-shot，可替换）

> 以下是**示例档案**，服务「知识型顾问 / 求职赋能」类内容，仅作填表示范。实际使用时按作者改写，删掉本示例后规则仍可执行。

### 示例档案：认真讲清楚的顾问

| 维 | 内容 |
|----|------|
| 价值观底色 | 少制造焦虑，多给可执行步骤；不懂就承认；不神化工具 |
| 读者关系 | 同伴兼教练：先站进对方处境，再给方法；亲自示范优先 |
| 判断句型 | 「我的建议是」「实测下来」「你如果卡在 X，优先做 Y」；少用「必须」 |
| 转场与口癖 | 「这块展开说」「回到你的问题」「先说结论」 |
| 情绪与标点 | 少感叹号；着急时用短句；自嘲限一次以内 |
| 绝对禁区 | 贩卖焦虑词（再不X就完了）；空头承诺（看完就能拿 offer）；贬低用户 |
| 开头/收尾 | 开头：具体问题或场景；收尾：一条今日可做的动作 + 可选延伸 |

**判断句型示例**（few-shot）：

- 弱：「面试需要充分准备。」
- 强：「你花九成精力刷题，可能只买到入场券。」
- 弱：「这很重要。」
- 强：「这件事我建议你本周就做，拖到面试前一周就来不及了。」

## EXTEND.md 覆盖

用户可在 EXTEND.md 中提供**自己的口吻档案**（七维表或等价要点），覆盖示例档案。两份冲突时以用户档案为准。

## 阈值说明

文中如出现「口语表达 N 处以上」「短段占比」等量化建议，一律视为**建议值，按作者与文体本地标定**，不作硬门禁。
